# Python 基本语法 Resources

## Knowledge

- [官方教程：The Python Tutorial（中文版）](https://docs.python.org/zh-cn/3/tutorial/index.html)
  Python 官方教程，权威且免费，有官方中文翻译。Use for: 一切语法问题的最终依据。
- [官方参考：内置类型 Built-in Types](https://docs.python.org/zh-cn/3/library/stdtypes.html)
  str/list/dict 等所有方法的权威列表。Use for: 查某个类型有哪些方法。
- [Book: _Automate the Boring Stuff with Python_ — Al Sweigart（免费在线）](https://automatetheboringstuff.com/)
  面向零基础到实用脚本，练习驱动。Use for: 语法学完后的实战练习方向。
- [Python Cheatsheet](https://www.pythoncheatsheet.org/)
  基于 Automate the Boring Stuff 的社区速查表。Use for: 快速回忆语法。

## Wisdom (Communities)

- [r/learnpython](https://reddit.com/r/learnpython)
  高信噪比的初学者社区，有严格版规。Use for: 提问、代码点评。
- [Python Discord](https://pythondiscord.com/)
  大型实时社区，有专门的 help 频道。Use for: 实时答疑。
- [V2EX Python 节点](https://www.v2ex.com/go/python)
  中文社区。Use for: 中文环境的求职/技术讨论。
