第 1 课：变量与核心类型

Python 基本语法 · 约 12 分钟 · 任务：转行求职

本课目标

会声明变量，认识 Python 的 4 个最常用类型（int、float、str、bool），并用 f-string 拼出输出。这是后面一切的地基。

1. 变量：没有类型声明

你写过其他语言，所以直说区别：Python 变量不需要声明类型，也没有 var/let 关键字。赋值即创建：

age = 28          # int（整数）
price = 19.9      # float（浮点数）
name = "小王"      # str（字符串，单双引号都行）
hired = True      # bool（注意首字母大写：True / False）
类型跟着值走，不跟着变量走。同一个变量可以先存数字再存字符串——合法，但求职代码里别这么干，可读性差。

2. 用 type() 查看类型

type(age)     # <class 'int'>
type(price)   # <class 'float'>

在交互式解释器（终端输入 python3）里随手试，这是学 Python 最快的反馈环。

3. f-string：拼字符串的标准姿势

字符串前加 f，花括号里可以放任何表达式：

name = "小王"
age = 28
print(f"{name} 今年 {age} 岁，明年 {age + 1} 岁")
小王 今年 28 岁，明年 29 岁

笔试和工作代码几乎只用 f-string，不用 + 拼接（"a" + 28 会直接报错，因为 Python 不会自动把数字转成字符串）。

4. 类型转换要显式

x = input("输入一个数字: ")   # input() 返回的永远是 str
n = int(x)                    # 显式转成 int 才能做算术
print(n * 2)
