第 3 课：条件分支与逻辑运算

Python 基本语法 · 约 12 分钟 · 前置：第 2 课

本课目标

你上节课已经自己用对了 if，所以这课节奏快一点：补齐 elif/else、逻辑运算符，最后用一道经典笔试题 FizzBuzz 收尾。

1. if / elif / else

score = 85
if score >= 90:
    print("优秀")
elif score >= 60:      # elif = else if，可以有多个
    print("及格")
else:
    print("不及格")

从上往下逐个判断，命中第一个就停，后面的不再看。所以条件的顺序很重要。

2. 比较与逻辑运算符

写法含义注意
== / !=等于 / 不等于= 是赋值，== 才是比较
and / or / not与 / 或 / 非是英文单词，不是 && || !
18 <= age < 60链式比较Python 特色，可以连着写
x in nums成员判断list、str 都能用
age = 25
if 18 <= age < 60 and age != 30:
    print("符合条件")

if "王" in "小王":       # in 判断子串
    print("找到了")

3. 取余运算 %：笔试高频

7 % 3      # 1 —— 7 除以 3 的余数
6 % 3      # 0 —— 余数为 0 说明整除
n % 2 == 0   # 判断偶数的标准写法

随堂检验

动手练习：FizzBuzz（经典笔试题）

写一段代码，遍历 1 到 20（提示：range(1, 21)）：

  • 能被 3 和 5 同时整除 → 打印 FizzBuzz
  • 只能被 3 整除 → 打印 Fizz
  • 只能被 5 整除 → 打印 Buzz
  • 其他 → 打印数字本身
提示：分支顺序很关键——想想为什么「同时整除」必须放在最前面判断。这道题建议写成 fizzbuzz.py 文件跑（REPL 里写多行容易缩进出错），写完发我点评。
