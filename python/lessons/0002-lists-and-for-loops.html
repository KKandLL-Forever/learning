第 2 课：list 与 for 循环

Python 基本语法 · 约 12 分钟 · 前置：第 1 课

本课目标

会创建和操作 list（列表），会用 for 循环遍历，会用 range()。这是笔试题中出现频率最高的组合。

1. list：有序、可变、什么都能装

scores = [90, 85, 77]
names = ["小王", "小李"]

scores[0]        # 90 —— 下标从 0 开始
scores[-1]       # 77 —— 负数从尾部数，-1 是最后一个
len(scores)      # 3  —— 长度
scores.append(60)   # 尾部追加 → [90, 85, 77, 60]
你写过其他语言，注意两个 Python 特色：负下标（[-1] 取末尾）和 len() 是函数不是方法（写 len(x) 不是 x.length）。

2. for 循环：直接遍历元素

Python 的 for 不是 for (i=0; i<n; i++)，而是直接拿到每个元素：

for name in names:
    print(f"你好, {name}")
你好, 小王
你好, 小李
缩进就是语法。循环体必须缩进（惯例 4 个空格），没有花括号。缩进错了程序直接报错或逻辑改变——这是 Python 和其他语言最大的不同。

3. range()：需要数字序列时

for i in range(5):        # 0, 1, 2, 3, 4 —— 不含 5
    print(i)

for i in range(1, 4):     # 1, 2, 3 —— 含头不含尾
    print(i)

「含头不含尾」是 Python 的通用约定，切片也一样，记住这一条能避开一大类 off-by-one 错误。

4. 组合拳：累加

scores = [90, 85, 77]
total = 0
for s in scores:
    total = total + s     # 也可写 total += s
print(f"平均分 {total / len(scores)}")
平均分 84.0
