变量与类型

类型示例说明
intage = 28整数，无大小限制
floatprice = 19.9浮点数
strname = "小王"单双引号均可
boolok = TrueTrue / False 首字母大写

常用操作

type(x)              # 查看类型
int("5"), str(5)     # 显式类型转换
float("1.5")
f"{name} 今年 {age} 岁"   # f-string（首选拼接方式）
f"{age + 1}"         # 花括号内可放表达式
input("提示: ")       # 读输入，返回值永远是 str
print(a, b)          # 打印，逗号分隔自动加空格

list 与 for 循环

nums = [10, 20, 30]
nums[0], nums[-1]    # 首个 10，末个 30（负下标从尾数）
len(nums)            # 长度（函数，不是 .length）
nums.append(40)      # 尾部追加

for n in nums:       # 直接遍历元素
    print(n)         # 循环体靠缩进（4 空格）

range(5)             # 0..4
range(1, 4)          # 1..3 —— 含头不含尾（通用约定）

条件与逻辑

if score >= 90:       # 命中第一个分支就停
    ...
elif score >= 60:     # elif 可有多个
    ...
else:
    ...

==  !=                # 比较（= 是赋值）
and  or  not          # 逻辑运算符（英文单词，非 && || !）
18 <= age < 60        # 链式比较
x in nums             # 成员判断（list / str 通用）
n % 2 == 0            # 取余；判断偶数标准写法

易错点

  • "a" + 3 → TypeError，str 与 int 不能相加
  • true → NameError，必须写 True
  • input() 返回 str，做算术前先 int()
  • 缩进不一致 → IndentationError，循环/条件体统一 4 空格
  • range(3) 不包含 3——含头不含尾
