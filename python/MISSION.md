# Mission: Python 基本语法

## Why
用户想转行/求职，需要把 Python 作为职业级编程技能系统掌握。学会基本语法是通往能写出可用于工作的代码（数据处理、自动化、面试笔试）的第一步。

## Success looks like
- 能独立读懂并写出包含变量、条件、循环、函数的 Python 脚本
- 能熟练使用 list / dict / str 等核心数据类型解决小问题
- 能通过初级 Python 笔试题（如 FizzBuzz、字符串处理、简单数据统计）
- 后续可无障碍进入下一阶段（标准库、文件处理、项目实战）

## Constraints
- 学习时间不固定，课程需短小、可随时中断和恢复
- 有其他语言基础（懂变量和循环的概念），不必从"什么是编程"讲起
- 中文教学

## Out of scope
- Web 框架（Django/Flask）、数据科学库（pandas/numpy）——语法过关后再说
- Python 内部机制（GIL、内存模型）——面试进阶话题，暂缓
