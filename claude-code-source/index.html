课程总览

Claude Code 源码架构

从一个 150 行的极简内核出发，每课加一个模块，逐步逼近 D:\code\claude-code-source 的真实架构。主教材是源码仓库的 架构报告（16 章）。

学习目标为什么学这个 · 双目标 速查 · 术语表这门课的统一说法 资源清单一手源码 + 官方博客 架构报告主教材全文

课程

  • 01 极简内核 150 行写出和 query.ts 形状相同的运行时。生成器、终止原因、显式状态。 可学
  • 02 工具契约 47 个成员不是设计失误，有五种消费者在看它。fail-closed 默认值，以及它救不了的那一个成员。 可学
  • 03 并发分批 只读的并发，写入的串行。关键在「相邻」两个字，以及为什么合流要自己写而不能用 Promise.all。 可学
  • 04 权限判定顺序 10 步固定顺序，位置本身就是安全语义。为什么 bypass 模式排在第 7 位而不是第 1 位。
  • 05 结果预算 一次 npm test 吐 800KB 日志怎么办。落盘 + 预览 + 路径。
  • 06 Prompt Caching 前缀匹配的残酷后果，以及这个代码库里那些「为缓存做的让步」。
  • 07 三级压缩 微压缩是日常清扫，自动压缩是搬家，被动压缩是救火。
  • 08 Attachment 回灌 不要求模型记住任何东西：状态写出去，每轮再读回来。
  • 09 子 Agent 与 fork 上下文隔离与缓存命中，两个相反方向的权衡。

课程弧线会根据学习进度调整，见 NOTES.md。

代码

动手部分都在 mini-cc/，按版本分目录，旧版本保留，方便回看架构演进：

cd D:\code\learning\claude-code-source\mini-cc
bun install
bun run src/v0/main.ts "看看 src/v0 里有什么"   # 第 0001 课
bun run src/v1/main.ts "看看 src/v1 里有什么"   # 第 0002 课
bun run src/v2/main.ts "并发演示"              # 第 0003 课

没有 DEEPSEEK_API_KEY 也能跑，会自动切到离线剧本模式。

学习记录： 0001 · 循环的形状不难，难的是循环的管道
0002 · fail-closed 不是「默认值都往保守写」
0003 · 调度器不敢贪心，因为它读不懂意图
