速查：Agentic Loop 模式

Agentic Loop 是所有 AI Harness 的基础骨架。把这个模式背下来。

while (循环未结束) {
  1. 把 { 用户输入 + 历史消息 + 工具定义 } 发给 LLM
  2. 流式接收 LLM 输出（文本 或 tool_use）
  3. 如果输出是文本 → 结束循环，返回给用户
  4. 如果输出是 tool_use → 执行工具，把结果塞回历史消息
  5. 回到步骤 1
}

关键抽象

组件 职责 可替换？
ModelAdapter 封装 LLM 调用，统一 chunk 格式 ✓ DeepSeek / OpenAI / 本地模型
ToolRegistry 管理工具定义，执行工具并隔离错误 ✓ 按需增删工具
Agent Loop 编排模型调用、工具执行、状态流转 ✗ 核心逻辑，一般不动

错误处理原则

  • 工具执行失败 → 把错误信息作为 tool_result 返回给模型，让模型决定重试或解释
  • 模型 API 失败 → 抛异常给外层，记录日志，可配置重试
  • 循环超过最大轮数 → 安全退出，返回已生成的内容

消息历史格式

[
  { role: "system", content: "你是一个 helpful 助手。" },
  { role: "user", content: "北京今天天气怎么样？" },
  { role: "assistant", content: "我帮你查一下北京的天气。" },
  { role: "user", content: [
    { type: "tool_result", tool_use_id: "tool_1", content: "北京当前天气：晴天，25°C" }
  ]}
]
