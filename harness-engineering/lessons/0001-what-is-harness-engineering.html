第 0001 课：什么是 Harness Engineering？

Harness Engineering 是 AI 时代的一个新工程范式。它描述的是构建、编排和控制 AI Agent 系统的工程实践——就像汽车引擎需要线束（harness）来连接各个电子部件一样，AI Agent 需要一套"软件线束"来连接模型、工具、内存和用户。

你每天都在使用一个 Harness。Claude Code 本身就是一个 Harness——它在持续循环中编排模型调用、工具执行、文件读写和用户交互。问题不是"什么是 Harness？"而是"我怎么自己造一个？"

核心概念：Agentic Loop

每一个 Harness 的核心都是同一个模式——Agentic Loop（代理循环）：

这个循环的三个阶段：

  1. 输入 → 模型：用户输入 + 系统 prompt + 工具定义 → 发送给 LLM
  2. 模型 → 决策：模型决定是返回文本还是调用工具
  3. 工具 → 回到模型：执行工具，结果返回给模型，直到模型决定停止

最小可运行 Harness

下面是一个 30 行 TypeScript 的最小 Agentic Loop（用 OpenAI SDK 连接 DeepSeek——DeepSeek 提供 OpenAI 兼容接口，只需改 baseURL）：

import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.DEEPSEEK_API_KEY,
  baseURL: "https://api.deepseek.com",   // ← 关键：指向 DeepSeek
});
const MODEL = "deepseek-chat";

async function run(prompt: string) {
  const messages: any[] = [{ role: "user", content: prompt }];

  while (true) {
    const res = await client.chat.completions.create({
      model: MODEL,
      messages,
      tools: [{
        type: "function",
        function: {
          name: "get_weather",
          description: "获取指定城市的天气",
          parameters: {
            type: "object",
            properties: { city: { type: "string" } },
            required: ["city"]
          }
        }
      }]
    });

    const msg = res.choices[0].message;
    messages.push(msg);

    // 模型没有要调用工具 → 结束循环，返回文本
    if (!msg.tool_calls) {
      return msg.content;
    }

    // 模型要调用工具 → 执行，把结果作为 role:"tool" 消息塞回历史，继续循环
    for (const call of msg.tool_calls) {
      const args = JSON.parse(call.function.arguments);
      const result = await executeTool(call.function.name, args);
      messages.push({
        role: "tool",
        tool_call_id: call.id,
        content: result
      });
    }
    // ← 循环回到 while(true)，模型拿到结果后继续推理
  }
}

这 30 行代码就是 Harness 的最简形式。真实的 Harness（如 Claude Code）只是在这个核心循环上加了更多层：

  • 工具注册与发现——怎么声明有哪些工具可用
  • 状态管理——对话历史、文件系统、内存
  • 错误恢复——工具调用失败时怎么办
  • 多 Agent 编排——一个 Agent 调用另一个 Agent
  • 人机交互——权限确认、中途干预

小测验

第 1 题

Agentic Loop 的核心决策点是什么？

模型是否生成了超过 1000 个 token
模型返回的是文本还是工具调用
用户的输入是否包含特殊字符
网络连接是否仍然存活

第 2 题

以下哪个不是 Harness 的核心职责？

管理模型调用和工具执行的循环
训练和微调底层大语言模型
处理工具调用失败和错误恢复
在多 Agent 之间传递上下文和状态
