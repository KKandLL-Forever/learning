# 学习目标：Harness Engineering（AI 时代）

## 为什么要学这个

我是一名 Web 前端工程师，日常使用 JavaScript/TypeScript。AI Agent 正在改变软件开发的方式——从单一的 LLM 调用到多 Agent 协作系统。我需要掌握构建、编排和控制 AI Agent 系统的工程能力，能够设计并实现一个完整的 Agents 项目。

**核心驱动力：** 在工作中搭建可投入生产的 Agent 项目，而非停留在 demo 阶段。

## 学成之后能做什么

- 我能独立设计和实现一个多 Agent 协作系统
- 我理解 Agent 架构的核心模式：Tool Use、Memory、Orchestration、Evaluation
- 我能从前端工程师的视角，构建与 Agent 系统交互的用户界面
- 我能在工作中落地一个实际可用的 Agent 项目

## 约束条件

- 技术栈偏好：TypeScript/JavaScript 优先
- 学习时间：利用工作之余
- 目标产出：一个可运行的 Agent 项目，而非纯理论学习
- 语言偏好：除专业名词外，全部使用中文
